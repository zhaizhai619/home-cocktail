# 家庭调酒酒单小程序

> 不是另一个庞大的公共配方库，而是一个用来管理“属于自己的小酒单”的工具。

市面上的调酒小程序和 App，大多在解决“去哪里找更多配方”以及“如何分享配方”的问题。但今天找到一杯酒并不难：社交平台上每天都有新的配方、教程和灵感。真正麻烦的是，一条内容刷过去后可能再也找不到；临时想喝时，才发现配方需要提前浸泡两天，某瓶酒还要网购，手头的水果却已经快过期。

这个小程序想解决的不是“还有什么酒”，而是：

- 我收藏过哪些真正想喝的酒？
- 这些酒要提前多久准备，需要什么设备？
- 我家里现在有什么，还缺什么？
- 哪些材料今天就该优先用掉？
- 以我当前的环境和材料，哪一杯最适合现在做？

适合人群：

- 在社交平台收藏过不少调酒配方，真正想做时却总要翻很久；
- 家里或宿舍有一个规模不大、但舒适温馨的小吧台；
- 比起浏览上千杯酒，更关心“我今晚到底能做哪一杯”；
- 买过一袋柠檬、一盒薄荷或一瓶果汁，只用了一点，后来才发现它已经悄悄过期；
- 想记住自己喜欢的比例、材料和做法，而不是每次都从头查一遍。

不需要专业设备齐全，也不需要背下一整本鸡尾酒谱。只要你偶尔想给自己做一杯，又希望这件事更有条理一点，就可以从这里开始。

## ✨ 产品亮点

### 1. 🍸 管理自己的小酒单，而不是浏览别人的大酒库

看到喜欢的配方时，可以立即录入酒名、材料、制作方式、步骤和个人评价，建立只属于自己的酒单。以后想重做一杯酒，不必再翻收藏夹、聊天记录和浏览历史。

产品不以社交、点赞或公共配方数量为核心，而是关心一条配方进入个人生活之后，如何被保存、准备和真正做出来。

### 2. 录入一杯酒，不需要反复填写相同材料

金酒、白朗姆、伏特加等常用基酒，以及柠檬汁、糖浆等高频材料已经进入默认材料库。录入配方时可以按“基酒 / 利口酒 / 果汁果蔬 / 混合饮品”快速选择，也可以全库搜索或直接创建新材料。

新建配方时出现的新材料会自动进入个人材料库；提前准备中使用的材料也采用同一套逻辑，不需要之后再重复维护。预调成品、基酒和利口酒还会按更符合调酒阅读习惯的默认顺序展示，用户手动调整后则保留自己的排序。

### 3. ⏱️ 不只记录配方，还记录“什么时候才能做”

配方可以标记为即调、冷冻、冷泡/浸泡、奶洗、低温慢煮或其他，并记录需要提前几小时或几天准备。提前准备产生的混合果汁、浸泡酒等预调成品，可以连同它的详细材料和制作步骤一起保存。

这对家庭调酒尤其重要：宿舍可能没有冰箱，租房可能没有低温慢煮设备，工作日也未必有时间提前两天准备。制作方式和准备时长一目了然，并且可以直接按制作方式筛选；需要的酒杯和工具也会随配方保存，打开详情就能确认当前环境是否满足。

### 4. 🚦 用三种材料状态回答“现在能不能做”

材料不只是简单的“有”或“没有”，而是分成：

- **当前可用**：手头已经有，可以直接制作。
- **随买随用**：暂时没有，但外卖平台或附近超市通常可以买到，购买后即可制作。
- **长期材料缺少**：需要专门购买或等待到货，不能算作今天马上能补齐的材料。

酒单会直接展示缺少的是哪一种状态，也可以按手头材料、随买随用材料和制作条件筛选。材料详情还会告诉用户它被多少杯酒使用，以及买到它可以立即解锁多少杯酒。这样打开酒单时看到的不只是配方，而是这杯酒距离“现在能喝到”还有多远。

### 5. 🍋 鲜材余量和到期提醒，减少家庭调酒浪费

家庭调酒一次通常只会用掉半个柠檬、几片黄瓜或少量果汁。小程序可以记录鲜材的购买日期、剩余量和预计到期日，并在需要关注时提醒。用完后可以快速移出，误操作还可以撤销。

展开一项手头鲜材，就能看到会用到它的个人酒单。推荐顺序会优先考虑：

1. 一杯酒同时命中了多少种手头鲜材；
2. 其他材料是否已经齐全；
3. 配方用量单位是否与记录的余量单位匹配。

因此推荐的不只是“含有黄瓜的酒”，而是更适合当前库存、也更有机会立即做出来的酒。

### 6. 材料分类自带合理默认值，减少无意义的开关

不同材料的使用方式天然不同：基酒通常长期常备，水果通常随买随用并适合追踪保质期，苏打水更接近买来即可使用。小程序会根据材料分类自动填写获取方式、常备状态、默认单位和是否追踪鲜度，用户只在例外时修改。

这套默认逻辑减少了录入过程中的重复点击，同时仍允许每个人按自己的家庭吧台情况调整。

### 7. 保留自己的调酒经验，而不只是原始配方

同一种材料在不同品牌、成熟度或处理方式下可能表现完全不同。材料详情可以持续记录个人观察，例如“这瓶金酒杜松味更重”“这批柠檬偏酸”，记录可以编辑和删除。配方评价则帮助用户区分想尝试、值得复刻和不再考虑的酒。

### 8.  酒精度自动计算

根据液体材料和酒杯容量估算成品体积，并在资料完整时计算预估酒精度。


## 产品原则

- **个人优先**：仅服务自己的收藏和口味。
- **少填一次**：能由分类推断的状态不反复询问，能复用的材料不重复创建。
- **状态可行动**：不只说“缺材料”，还区分能否马上买到、是否需要提前准备。
